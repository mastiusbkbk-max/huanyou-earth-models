# 寰游 · 高保真实景模型资产

[打开寰游](https://mastiusbkbk-max.github.io/huanyou-earth-atlas/) · [网站源码](https://github.com/mastiusbkbk-max/huanyou-earth-atlas)

本仓库为独立的 GitHub Pages 数据站，发布寰游 PC 使用的 16 处实景及里昂专用地形。当前模型共 825,280,656 B、17 个完整目录、2,567 文件，保留每级 LOD、原始几何、UV、摄影纹理与来源资料，不进行纹理重编码、缩图或几何量化。

资源根：`https://mastiusbkbk-max.github.io/huanyou-earth-models/`。模型入口位于 `models/<片区>/tileset.json`，完整逐文件 SHA-256 位于 [asset-manifest.json](site/asset-manifest.json)。GitHub Actions 发布前会逐文件复核。

香港模型归香港特别行政区政府及相关机构所有，采用公开资料所附条款；赫尔辛基采用 City of Helsinki CC BY 4.0，里昂采用 Métropole de Lyon Licence Ouverte 2.0，墨尔本采用市政府资料所附开放许可。每个目录的 `source.json` 保留准确来源、具体许可、数据年份与处理记录；复用时须遵循原条款并保留署名。本仓库不将第三方地理资产重新许可为自有作品。

旧 `china-atlas` 仓库与网站没有被覆盖。全部历史 / 平板派生模型另以无损归档保存在主仓库 Release `pc-models-2026-10-23`。
